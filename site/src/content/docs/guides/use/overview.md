This guide is for working in the OCIDex web UI once it's running. If you're new, the
[quickstart](/getting-started/quickstart/) gives you a running instance with data in it, and
[Concepts](/concepts/overview/) explains the words the UI uses.

| Find an artifact, a package or a license | [Browse and search](/guides/use/browse/) |
| See what changed between two versions | [Compare SBOMs](/guides/use/compare/) |
| Find and triage vulnerabilities | [Vulnerabilities](/guides/use/vulnerabilities/) |
